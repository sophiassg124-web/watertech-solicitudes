WATERTECH - Solicitud de medidores (Python)
===========================================

Archivos necesarios en la misma carpeta:
- main.py
- fondo_watertech.png  (imagen de fondo enviada por el usuario)
- watertech.png
- slogan.png

Requisitos:
- Python 3.10 o superior
- Pillow para ajustar la imagen de fondo automáticamente

Instalar Pillow desde la terminal:
    python -m pip install Pillow

Ejecutar:
    python main.py
Si no funciona, prueba:
    py main.py

La aplicación ajusta el fondo al tamaño de la ventana. El logotipo y el eslogan ya están integrados
en la imagen de fondo, por eso no se dibuja un segundo logotipo en el encabezado.

Las solicitudes se guardan en:
Documentos\WatertechSolicitudes\solicitudes_watertech.csv

Nota normativa:
La referencia normativa es preliminar y debe verificarse con Watertech para cada tipo de proyecto.
